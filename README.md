# Занятость актеров театра

Проект для автоматизации организационно-финансовой работы театра:  
учёт спектаклей, контрактов с актёрами, распределение ролей и бюджетов.

## Функционал
- Планирование постановок спектаклей.
- Заключение контрактов с актёрами (сумма, роль, стаж, награды).
- Расчёт бюджета спектаклей.
- Отслеживание занятости актёров.
